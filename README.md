# مکتب — ردیاب عادت

- ریشه‌ی این ریپو نسخه‌ی ساخته‌شده‌ی اپ است که GitHub Pages نمایش می‌دهد (حالت محلی: بدون ورود، داده روی همان گوشی).
- کد کامل (کلاینت و سرور) در پوشه‌ی [`source/`](source/) است. راهنمای اجرا و راه‌اندازی سرور: [`source/README.md`](source/README.md).
- وقتی اپ روی سرور Node اجرا شود، ورود با شماره همراه، ذخیره‌ی داده روی سرور و یادآوری شبانه‌ی ساعت ۲۱:۳۰ خودکار فعال می‌شود.

به‌روزرسانی نسخه‌ی Pages: در `source/` دستور `npm ci && npm run build` را بزن و محتوای `source/dist/` را جایگزین فایل‌های ریشه کن.
